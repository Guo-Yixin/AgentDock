# 用量审计：多智能体的统一口径

## 界面与范围

采用 AgentDock 共用的冰蓝浅色、午夜深蓝和青绿强调色。网页版与 Electron 使用同一套组件；浅色筛选器、提示卡、图表及来源图标统一使用主题变量。轨道由 CSS 绘制，文字、控件和图表为真实组件。支持减少动态效果。

“用量审计”结合个人活动页与账单页：顶部为所有者资料、累计已记录 token、单日峰值、活跃天数与连续天数；中部为年度热力图和时间、工具、模型、项目筛选；下方为每日输入/缓存/输出堆叠图、估算费用、模型对比与分页证据明细。图表支持鼠标悬停与键盘读取（费用图采用原生悬停提示），每条记录可以查看文件、行号、压缩帧或数据库定位。

顶部历史统计和热力图使用所选工具、模型、项目的全部保留记录；日期筛选作用于明细和费用趋势。连续天数按上海自然日，截至今天或昨天。它表示存在正用量记录的日期，不代表工作时长。每日图补齐选定范围内的空白日期；空白仅表示未记录用量。

首版展示本机可解析用量，不能宣称覆盖所有平台账单。账号采用当前 MySQL 工作空间的单所有者模式；登录保护任务、路径、报告、设置、助手和用量接口。演示独立，使用合成图表，不创建真实账号、价格或请求。

## 统一记录

每条记录保存工具、原始会话、请求标识、模型、项目、记录时间、输入、缓存读取、缓存写入、输出、推理输出、来源定位和解析口径。只有明确 usage 字段参与统计；缺失字段保存为 NULL，不用字符数或模型文本推算。

统一计算：

```text
总 token = 输入（含缓存） + 输出（含推理）
普通输入 = 输入 - 缓存读取 - 缓存写入
```

推理输出是输出的子集，不再次累加。来源仅提供总量时保留总量，输入/输出继续显示“未提供”。缓存之和超过输入时标记异常，舍弃不可信缓存拆分。来源 tokenizer 不同，跨工具汇总仅是各来源报告的 token 之和，不表示文本等价算力。

| 来源 | 解析与去重 | 边界 |
| --- | --- | --- |
| Codex / CLI | `token_count.info.total_token_usage` 按历史高水位取正增量，忽略重复限流快照；模型取 `turn_context`。兼容 `token_usage_record`，出现累计口径后删除同会话直接口径，避免双计 | 归档/截断日志先合并快照，再统一计算高水位增量；累计快照不等同单次 API 请求；计数回退不负扣或重新累计。初次快照可能包含更早用量，按记录日归档 |
| Claude Code / CLI | `message.usage`，普通输入加缓存读取/写入；相同 message ID 的分段更新取各字段最大值 | 子代理保留独立会话和项目；只读取助手用量，不把工具事件当额外请求 |
| Pi | 助手 message usage，输入加 cacheRead/cacheWrite；节点 ID 去重，保留所有分支已发生的用量 | SDK cost 独立标记为 USD 估算，不当作实际账单 |
| DeepSeek Harness | `assistant/message.data.usage`，保留 turn、step、seq、行与压缩帧位置 | 兼容普通/拼接 Zstandard 日志；不可解析字段不补造 |
| WorkBuddy | message usage，以 providerData message/request ID 去重，提取来源模型 | 缺少请求 ID 时退回日志条目 ID；未知模型明确展示 |
| Cursor | 仅解析可读气泡明确提供的 usage/tokenUsage，保留 composer/bubble 依据 | 头部或正文缺失、无用量字段时不推算；不读取认证文件或远程私有账单 |
| AgentDock 助手 | 官方流式 usage 结果，每次生成分配独立审计 ID | 单独归为内置助手，模型调用只在用户确认后发生；没有返回 usage 的中断不会虚构 token |

同工具桌面/CLI 以原始会话 ID 去重；单次请求按请求 ID 或稳定条目 ID 去重，来源复制/归档重读不会叠加。日志重读与断点、会话、活动、用量在同一事务中提交，批量写入每次最多 100 条。数值型索引与日期聚合在 MySQL 执行，界面分页读取，不加载全部正文。

## 计价

不内置会随时间变化的“永久正确价格”。用户按工具、完整模型名、币种和生效日期保存每百万 token 单价：普通输入、缓存读取、缓存写入/5 分钟、1 小时缓存写入、输出。规则按记录发生时间选择最新适用版本，同日规则以后保存者为准。删除规则会按剩余规则重算历史估算。

```text
估算费用 = (普通输入 × 普通输入单价
          + 缓存读取 × 缓存读取单价
          + 短缓存写入 × 短缓存写入单价
          + 长缓存写入 × 长缓存写入单价
          + 输出 × 输出单价) / 1,000,000
```

缺失输入/输出、未知模型或无适用单价的记录不计价；页面显示已计价与未计价条目数。未报告缓存的输入暂按普通输入计价，明确提示可能高估。CNY 与 USD 独立汇总，不隐式换汇。模型列表显示使用来源，Pi 的 SDK 估算独立展示，不和自定义估算相加。

**金额不是实际账单。** 未读取平台余额、优惠、税费、服务层级、工具调用额外费用、订阅额度或峰谷价格。需要这些价格时可按适用模型合同填写规则；首版日期规则无法表达小时峰谷窗口。CSV 导出当前筛选范围的模型用量汇总，文件不携带密码、Key 或登录令牌。

## 密码与会话

新用户连接并初始化 MySQL 后创建自己的账号，仓库不携带通用默认账号。密码通过异步 scrypt（N=131072、r=8、p=1）与独立随机盐哈希后写入 `ad_users`。`ad_sessions` 仅保存随机令牌的 SHA-256；浏览器使用 HttpOnly、SameSite=Strict Cookie，默认 8 小时，主动选择可保持 7 天。当前服务为本机 HTTP，因此 Cookie 不使用 Secure；服务仍绑定 127.0.0.1 并校验 Host/Origin。不要把此本机服务直接暴露公网。

网页版与桌面版 Cookie 分开命名；桌面原有启动认证仍保留，启动认证不绕过账号登录。后台通知与托盘操作读取 Electron 当前登录 Cookie，退出后不再访问私人提醒。支持更改显示名称、修改密码、退出和吊销其他会话。修改密码吊销所有会话；退出停止对应 SSE/生成连接，常驻更新每 15 秒检查登录状态。采集可以继续在后台运行，阅读记录仍需要登录。
